# 台中區 FAE 測試資產智慧管理 (Cloud PWA)

跨手機（iOS / Android PWA）與多台筆電自適應之雲端測試資產管理前端介面。

## 架構與資安說明
- **純前端靜態介面**：本儲存庫僅包含 HTML / CSS / JS 前端介面與 PWA 圖示，**不含任何資產清冊、序號、客戶資料或 API 金鑰**。
- **雲端資料庫與驗證**：後端透過 Google Apps Script API 連結受保護之 Google Sheets 主檔，並由團隊專屬通行碼（PIN）進行存取控制。

## 主要功能
1. **📊 總覽與即時快搜**：支援筆電寬螢幕表格與手機卡片檢視，一鍵篩選儲位箱號、在庫／外借／逾 90 天預警，單鍵觸發借出與歸還。
2. **🔄 掃碼快速借還**：原生支援手機相機即時掃描 `90mm × 45mm` 設備 QR 貼紙及外接條碼槍。
3. **📦 分箱雙軌快盤**：支援免關鏡頭連續掃描盒外貼紙（內建嗶聲與震動回饋、放錯箱即時警示）及 Gemini AI 整箱拍照多標籤辨識。
4. **💬 AI 一句話記帳**：自然語言解析借還資訊並自動帶入表單。
