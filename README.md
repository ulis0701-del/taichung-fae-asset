# 台中區 FAE 測試資產智慧管理 (Cloud PWA v4.0)

跨手機（iOS / Android PWA）與多台筆電自適應之雲端測試資產全生命週期管理前端介面。

## 架構與雙層資安說明
- **純前端靜態介面**：本儲存庫僅包含 HTML / CSS / JS 前端介面與 PWA 圖示，**不含任何資產清冊、序號、客戶資料或 API 金鑰**。
- **雙層通行碼防護**：
  - **Team PIN（團隊通行碼）**：供團隊同仁日常查詢、掃碼借還、分箱快盤、新進測試品入庫與單張標籤列印。
  - **Admin PIN（管理員密碼）**：專供管理員執行主檔編修、RMA 換貨改序號、正式除帳歸檔、復原回庫與建檔錯誤永久刪除。

## 五大核心模組
1. **📊 總覽與即時快搜**：支援筆電寬螢幕表格與手機卡片檢視，一鍵觸發借還、單張補印 `90mm × 45mm` QR 貼紙及快速進入維護。
2. **🔄 掃碼快速借還**：原生支援手機相機即時掃描 QR 貼紙及外接條碼槍。
3. **📦 分箱雙軌快盤**：免關鏡頭連續掃描盒外貼紙（內建嗶聲與震動回饋、放錯箱即時警示）及 Gemini AI 整箱拍照多標籤辨識。
4. **🛠️ 庫存維護（新增／編修／除帳／刪除）**：依分類自動延續 `FAEMRM`、`FAEMIO`、`FAEMSW` 流水號、AI 拍外盒側標自動填單、四種標準除帳狀態歸檔與 `90mm × 45mm` 標籤機單張即印。
5. **💬 AI 一句話記帳**：自然語言解析借還資訊並檢視近期 30 筆雲端異動紀錄。
